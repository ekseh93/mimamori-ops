# Security policy

This is an educational MVP, not a production service with a security SLA.

Please use [private vulnerability reporting](https://github.com/ekseh93/mimamori-ops/security/advisories/new) for suspected vulnerabilities or credentials. Do not publish secrets, customer URLs or private logs in Issues, discussions or PR comments.

Include the affected commit/version, a minimal safe reproduction and the observed impact. Do not test against third-party sites without authorization. The maintainer will triage reports when available; no response-time guarantee is offered.

Only the current main branch is maintained. AWS deployment is currently disabled. This repository uses dependency alerts, dependency review, static analysis and public-content checks, but these do not certify the service as secure.
